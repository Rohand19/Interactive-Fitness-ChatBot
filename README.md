## 🏆 Introduction  
The **Interactive Fitness Chatbot** (FitBot) is an AI-based virtual assistant that provides fitness and health-related recommendations. It helps users with:  
👉 **Workout plans** based on fitness level  
👉 **Diet recommendations** for better nutrition  
👉 **Exercise tutorials** with form guidance  
👉 **Tracking progress** and setting fitness goals  

---

## 🔥 Features  
- 💪 **Personalized workout plans** tailored to your fitness level and goals
- 🥗 **Custom diet recommendations** for optimal nutrition
- 📊 **Progress tracking** to help stay motivated
- 🤖 **Conversational AI for interactive coaching** using AIML technology
- 📝 **Exercise guidance** with detailed instructions

---

## 🛠 Technologies Used  
- **Backend**: Java
- **AI Framework**: Program AB (AIML)
- **Build Tool**: Maven
- **Interface**: Command-line interface (with potential for GUI expansion)

## 🚀 Installation  
1️⃣ Clone the repository:  
```bash
git clone https://github.com/Rohand19/Interactive-Fitness-ChatBot.git
cd Interactive-Fitness-ChatBot
```

2️⃣ Make sure you have Java and Maven installed:
```bash
java -version
mvn -version
```

3️⃣ Build the project:
```bash
mvn clean install
```

4️⃣ Run the chatbot:
```bash
java -cp target/ChatBotDemoJavaProject-0.0.1-SNAPSHOT.jar com.howtodoinjava.demo.chatbot.Chatbot
```

---

## 🎯 Usage  
- Start the chatbot using the command above
- Interact with FitBot via text commands in the console
- Ask questions about fitness, workouts, or nutrition
- Request personalized workout plans based on your fitness level
- Get diet recommendations and nutritional advice

Sample interactions:
```
Human: What workouts are good for beginners?
Robot: For beginners, I recommend starting with bodyweight exercises like squats, push-ups, and lunges. Start with 2-3 sets of 10-15 reps, 2-3 times per week. 
```
